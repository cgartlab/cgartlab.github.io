# 隐私政策

**最后更新日期：2026 年 5 月 28 日**

## 引言

CG 艺术实验室（以下简称"本站"）高度重视用户的隐私保护。本隐私政策旨在向您说明，当您访问本站时，我们收集哪些信息、如何使用这些信息以及您享有的相关权利。

请您在使用本站服务前仔细阅读本政策。访问本站即表示您同意本隐私政策的条款。如果您不同意本政策的任何内容，请停止使用本站服务。

---

## 一、信息收集范围

### 1.1 您主动提供的信息

当您使用本站以下功能时，可能需要您主动提供相关信息：

- **评论功能**：通过 Giscus（基于 GitHub Discussions）发表评论时，您需要提供 GitHub 账号信息，相关数据处理遵循 GitHub 的隐私政策
- **邮件订阅**：订阅周刊时，您提供的电子邮箱地址
- **联系方式**：通过电子邮件与本站联系时，您自愿提供的姓名、邮箱及沟通内容

### 1.2 自动收集的信息

当您浏览本站时，以下信息可能被自动记录：

- **设备信息**：浏览器类型及版本、操作系统、设备型号
- **网络信息**：IP 地址（匿名化处理后）、网络服务提供商
- **浏览行为**：访问页面、停留时长、点击路径、来源页面
- **语言偏好**：浏览器设置的语言及地区信息

### 1.3 浏览器本地存储

本站使用浏览器本地存储（LocalStorage）保存以下信息：

| 存储类型 | 用途                           | 生命周期               |
| -------- | ------------------------------ | ---------------------- |
| 主题偏好 | 记录您选择的亮色/暗色主题模式  | 持久性（直到手动清除） |
| 搜索历史 | 记录您的搜索关键词（可选功能） | 会话级                 |

### 1.4 本站不收集的信息

- 本站**不收集**用户的真实姓名、身份证号、住址、电话号码等个人敏感信息
- 本站**不存储**用户的密码或支付信息
- 本站**不追踪**用户在其他网站的活动

## 二、信息使用目的

我们使用收集的信息用于以下目的：

### 2.1 网站运营与优化

- 分析网站流量和用户行为，优化内容布局和用户体验
- 监测网站性能，排查技术故障
- 了解读者兴趣偏好，改进内容质量

### 2.2 内容服务

- 发送周刊邮件订阅内容（仅在您主动订阅后）
- 回复您通过邮件提出的咨询或反馈
- 在评论区与您进行互动交流

### 2.3 安全与合规

- 防范恶意攻击、垃圾信息和滥用行为
- 遵守适用法律法规的要求

## 四、Cookie 与本地存储

### 4.1 什么是 Cookie

Cookie 是网站存储在您浏览器中的小型文本文件，用于记录您的偏好设置和浏览状态。

### 4.2 本站使用的 Cookie

| Cookie 类型 | 用途                              | 有效期                 |
| ----------- | --------------------------------- | ---------------------- |
| 主题偏好    | 记录您选择的亮色/暗色主题模式     | 持久性（直到手动清除） |
| 分析 Cookie | Google Analytics 用于区分独立访客 | 2 年                   |

### 4.3 浏览器本地存储

除 Cookie 外，本站还使用浏览器的 LocalStorage 功能：

| 存储键         | 用途             | 说明                       |
| -------------- | ---------------- | -------------------------- |
| `theme`        | 主题模式         | 值为 `light` 或 `dark`     |
| `theme-manual` | 是否手动设置主题 | 值为 `true` 时忽略系统偏好 |

### 4.4 您的隐私控制权

您可以通过以下方式管理 Cookie 和本地存储：

- **浏览器设置**：在浏览器偏好设置中清除、阻止或管理 Cookie
- **分析工具退出**：
    - [Google Analytics 退出](https://tools.google.com/dlpage/gaoptout)
- **减少动画效果**：如您的系统偏好设置 `prefers-reduced-motion: reduce`，本站将自动禁用页面动画
- **隐私浏览模式**：使用浏览器的隐私/无痕模式访问本站

**注意**：禁用必要 Cookie 或清除本地存储可能影响本站的正常功能（如主题切换记忆）。

## 五、数据安全

### 5.1 安全措施

本站采取以下措施保护您的信息安全：

- 全站启用 HTTPS 加密传输（SSL/TLS）
- 网站托管于 Cloudflare Workers，继承其企业级安全防护（包括 DDoS 防护、WAF 等）
- 定期更新系统和依赖组件，修补安全漏洞
- 限制对个人信息的访问权限

### 5.2 数据保留期限

- 分析数据：Google Analytics 默认保留 26 个月（已设置为自动删除）
- 评论数据：存储于 GitHub Discussions，遵循 GitHub 的数据保留政策
- 邮件订阅：保留至您主动取消订阅为止
- 本地存储数据：由您自行管理，可通过浏览器设置清除

### 5.3 安全事件响应

如发生数据泄露等安全事件，我们将：

- 在 72 小时内评估事件影响
- 如涉及个人敏感信息泄露，将及时通知受影响用户
- 采取补救措施防止事件扩大

如您发现个人信息有误，有权要求我们更正。

### 6.4 删除权

在以下情况下，您有权要求我们删除您的个人信息：

- 信息收集违反法律法规
- 信息使用超出约定目的和范围

### 6.6 数据可携带权

### 6.7 撤回同意权

您有权随时撤回此前授予的同意，不影响撤回前基于同意进行处理的合法性。
