# 作品介绍

Inkard 是一个在线卡片生成器，将文字、引用、列表一键转换为精美卡片图片。专为小红书、公众号、Instagram 等社交平台设计，所有渲染在浏览器本地完成，不上传任何数据。

# 创作动机

做内容创作时，经常需要将一段话、一个列表变成精美的图片发社交平台。每次打开 PS 调整字体、排版、配色都很繁琐——文字稍有改动就要重来一遍。

我想要一个工具：粘贴文字、选个模板、直接导出。所以写了 Inkard。

# 为什么做成开源

这类工具市面上很多，但大多需要登录、有水印、或者导出要付费。Inkard 的核心逻辑是纯前端 Canvas 渲染，完全可以本地运行。开源出来，有需要的人可以直接用，也可以自己部署。

# 功能特点

## 设计能力

- **4 套模板**：极简 / 渐变 / 现代 / Editorial，风格各异
- **6 种配色方案**：橄榄绿 / 石板灰 / 玫瑰红 / 琥珀金 / 水墨黑 / 天空蓝
- **3 种字体**：现代无衬线 / 优雅衬线体 / 等宽代码体
- **暗色模式**：自动跟随系统，支持手动切换
- **OKLch 色彩**：基于 OKLch 色彩空间，色彩感知均匀

## 内容处理

- **4 种内容类型**：引用、列表、文章、简洁
- **实时预览**：表单编辑，所见即所得
- **批量导入**：Markdown（`##` 分隔多张）或 JSON 格式，一次生成整套
- **Frontmatter 支持**：Markdown 文档头可指定标题、作者、标签等元信息

## 怎么用

打开 [inkard.cgartlab.com](https://inkard.cgartlab.com)，三分钟就能做出第一张卡片：

**第一步：粘贴文字**

在左侧编辑区输入内容。可以是一段引言、一个列表，或者几行文字。支持用 Markdown 格式（比如 `##` 分隔多个区块），也支持粘贴纯文本。

**第二步：选模板和配色**

- 从 4 套模板里挑一个：极简风适合干净排版，渐变风适合吸引眼球，现代风适合科技内容，Editorial 风适合杂志感
- 从 6 种配色里挑一个：橄榄绿（适合自然主题）、石板灰（适合专业内容）、玫瑰红（适合情感内容）……
- 从 3 种字体里挑一个：无衬线（现代）、衬线（优雅）、等宽（技术）

选完这些，右侧会实时预览效果，改什么都立刻看到变化。

**第三步：选尺寸，导出**

根据你要发哪个平台选尺寸：发小红书选 3:4，发 Instagram 选 1:1 或 4:5，发公众号或通用场景选 16:9。点「导出」按钮，卡片图片就下载到本地了。不登录、不收费、没有水印。

### 多平台尺寸

| 比例 | 尺寸 | 适合平台 |
|------|------|----------|
| 3:4 | 1080 × 1440 px | 小红书 |
| 1:1 | 1080 × 1080 px | Instagram 方形 |
| 4:5 | 1080 × 1350 px | Instagram 竖版 |
| 16:9 | 1920 × 1080 px | 公众号 / 通用 |

### 批量生成

如果你想一次做一整套卡片（比如写系列内容），可以写成 Markdown 文件，用 `##` 分隔每张卡片的内容，然后一次性导入。Inkard 会自动按模板批量生成，不需要一张张复制粘贴。

## 技术架构

- **Astro 7 + React 18**：Islands 架构，仅交互组件加载 JS
- **Tailwind v4**：原子化 CSS
- **Canvas 导出**：浏览器端渲染，数据不上传
- **Cloudflare Workers**：全球边缘部署
