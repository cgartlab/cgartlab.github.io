说实话虽然它更广为人知的名字是 RIME，但让我一直记得的是"中州韵"，莫名喜欢。

第一次用是 2019 年，在异次元软件世界上看到推荐"小狼毫输入法"，出于好奇尝试一番之后觉得设置过于繁琐了，当时对于编程涉猎尚浅，如今接触了一点前端开发的领域后，逐渐领会到了编程的工作理念，而且 RIME 也覆盖了全平台，就决定再尝试一次。

没想到，还有一些意外收获。

## 为什么是 RIME：输入法即操作系统

很多人用搜狗、QQ 拼音，一用十几年，没觉得有什么问题。我也不想说"XX 比 XX 好"这种废话，但 RIME 解决的是一个不同层级的问题。

- **数据完全本地化**：不会上传你的输入记录到服务器，适合对隐私敏感的用户（搜狗/QQ 拼音是联网的）
- **跨平台一致性**：Windows（小小信使）、macOS（清歌）、Linux（ibus-rime）、Android（静网盘），同一套配置走天下
- **完全可编程**：输入法引擎本身是规则驱动的，你可以改任何一条映射逻辑，甚至自己写输入方案（如五笔、郑码、电报码）
- **无广告、无推荐词、无弹窗**：这是最让我舒服的地方，输入框永远干净，不会突然冒出一个"今日热词"
- **开源社区活跃**：仓耳症、星空键道、北邮等民间方案持续更新，总有一款适合你的输入习惯

## 核心概念：schema、yaml 和部署位置

RIME 的配置体系看起来复杂，其实只要理解三个概念就能入门。

- **Schema（输入方案）**：一种具体的输入法规则，比如"明月拼音""五笔""郑码"，每种方案有自己的 `*.schema.yaml` 配置文件
- **YAML（配置文件格式）**：所有配置都是 YAML 文本，结构简单，可读性强，改完重新部署即可生效
- **用户文件夹 vs 系统文件夹**：用户配置放在 `~/Rime/`（Windows 是 `%APPDATA%\Rime\`），覆盖系统默认方案，互不影响

## Windows 安装小小信使：踩坑记录

RIME 在 Windows 上的发行版叫"小小信使"（Weasel），安装过程有几个坑需要注意。

- **去 GitHub 下载最新 release**：官方域名有时被墙，推荐从 [RIME GitHub Releases](https://github.com/rime/weasel/releases) 页面下载 `Weasel-x.x.x.exe`
- **安装路径不要有中文**：这是 Windows 软件的老毛病了，路径含中文可能导致部署失败
- **安装完成后，右键托盘图标 → 重新部署**：这一步会编译用户的 YAML 配置并加载生效，必须做
- **托盘图标是灰色的=未生效**：如果部署后图标还是灰色，大概率是 YAML 语法错误，用 [YAML 在线校验工具](https://www.yamllint.com/) 检查配置文件
- **第一次部署会生成默认用户文件夹**：里面的 `default.yaml` 是全局配置，`用户文件夹_schema.yaml` 是具体方案的本地覆盖配置

## 配置自己的输入方案：从明月拼音到双拼

默认的"明月拼音"对全拼用户友好，但如果想提升打字速度，双拼是下一个台阶。

- **双拼的原理**：声母和韵母各映射到一个键，例如"双 = UD"，2 键打一个字，比全拼的 3-4 键大幅提速
- **推荐入门方案：智能 ABC 双拼**：规则简单，对新手友好，不用背太多映射
- **进阶方案：微软双拼或自然码**：覆盖更多边缘韵母，但需要配合肌肉记忆练习
- **修改 `用户的schema.yaml` 中的 `speller/algebra`**：把全拼的模糊音规则注释掉，改为双拼映射规则，然后重新部署
- **选词策略优化**：在 `*.schema.yaml` 中调整 `translator/enable_sentence: true`，开启整句输入，提升长句输入准确率

## 进阶：自定义词库与个性化配置

RIME 最强大的地方在于可以完全掌控自己的词库和行为逻辑。

- **导入搜狗词库**：网上有工具可以把搜狗细胞词库（`.scel`）转换为 RIME 可用的 `.txt` 词库格式，导入后重新部署即可
- **自定义短语**：在 `default.yaml` 的 `translator/dictionary` 下添加 `phrase:` 条目，比如常用地址、邮箱、签名档，打一个快捷键自动上屏
- **开启 Lua 脚本扩展**：RIME 支持 Lua 插件，可以做日期时间即时插入、一键计算等高级功能（需要 rime-luna 插件支持）
- **Emoji 方案**：装 `rime-emoji` 或 `rime-symbols` 扩展，输入 `bq` 触发表情菜单，设计师表达情绪再也不用手选
- **多语言混输**：同一方案内支持中英混合输入，配置 `switches/@0/reset` 规则，不用切换输入法就能打英文

## 用了一年后：我的真实感受

一年多下来，RIME 已经完全取代了搜狗输入法，成了我最核心的生产力工具之一。

- **打字速度提升了 20%**：双拼 + 整句输入，长句输入几乎不用选词
- **隐私安全感**：知道自己的输入记录不会被卖给广告商，心理上轻松很多
- **配置一次，长期受益**：不像商业输入法那样每次重装都要同步账号，rime 文件夹直接复制走，换设备 5 分钟搞定
- **折腾的过程也是学习**：接触了 YAML、Lua、正则表达式这些通用技能，对我后来理解 [RSS 与现代阅读习惯（三）：我的信息收集工具链整合方案](/posts/rss-and-modern-reading-part3/) 中的配置文件管理也有帮助

当然，RIME 不是银弹。如果你追求"开箱即用、0 配置"，它不适合你。但如果你愿意花一个下午理解它的设计逻辑，你会得到一个真正属于你自己的输入法——这也是我在折腾 [RSS 与现代阅读习惯（三）：我的信息收集工具链整合方案](/posts/rss-and-modern-reading-part3/) 时领悟到的同一原则：数据本地化 + 可迁移配置，才是长期主义的数字生活
